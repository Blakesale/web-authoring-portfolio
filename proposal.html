Final Project Part 1: Site Proposal

CTS1831C Web Authoring I • Blake Jakob

1. Purpose and Target Audience

The goal of this site is to create a personal portfolio that brings together my software projects and web authoring coursework.

Target Audience: Recruiters and people I collaborate with on programming and audio projects.

2. Career Goals and Research

I am working toward a role in software development, focusing on C++ and backend systems while building clean, accessible web interfaces. Tech recruiters look for practical proof that you can write code and be creative when it comes to personal projects. This portfolio will highlight a few key areas:

  • Software & Tools: Projects like my C++ board game (Hero's Journey), my JUCE audio sampler plugin, and custom trading strategies built through MCP connections.
  • Web Foundations: Responsive layouts built with semantic HTML5 and clean CSS without relying on external UI libraries.
  • Background: My coursework here at Broward College.

Industry Research & Citations

According to the U.S. Bureau of Labor Statistics, jobs for web developers and digital designers are projected to grow 5% through 2035. The BLS notes that having an active portfolio showcasing working code and responsive design is a crucial detail employers look for when hiring (BLS Web Developers Outlook).

An article by freeCodeCamp on developer portfolios explains that technical hiring managers prefer simple, fast-loading sites with direct links to GitHub repositories over complicated designs that hide the code (freeCodeCamp Portfolio Guide).

3. Planned Site Map (5 Pages)

The finished site will have five main pages linked together:

  1. Home (index.html): A quick introduction with links to my work and projects.
  2. Projects (projects.html): Breakdowns of my C++ programs and web authoring coursework.
  3. Skills (skills.html): Languages and tools I use (C++, HTML/CSS, Git, CLion, VS Code, macOS).
  4. Resume (resume.html): A clean web version of my education and IT courses at Broward College, as well as any internship experience.
  5. Contact (contact.html): A contact form along with links to my GitHub and email.
